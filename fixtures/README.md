# Fixtures

Recorded / redacted / synthetic test data. Everything here is either rights-cleared synthetic
data or redacted captures; **no secrets, no credentials, no live user content**.

## Files

- `sse_openai_compatible.txt` — a synthetic OpenAI-compatible chat-completion SSE stream used to
  exercise `SSEParser` + `ChatStreamParser` deterministically. Not a real provider capture.

## Policy

- Fixtures support repeatable deterministic tests. Passing a fixture test is **not** a
  live-integration claim (see `docs/TESTING.md`).
- Recorded protocol captures must be redacted before commit.
- Audio/animation fixtures are generated by `TestTTS`/the engineering rig, not recorded speech.
